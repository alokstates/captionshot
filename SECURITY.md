# Security

## Supported versions

Security fixes go into the [latest release](https://github.com/alokstates/captionshot/releases/latest). To update,
run the install command in the [README](README.md#install) again.

## Reporting a problem

Please don't post the details of a security problem in a public issue, because that puts other users at risk.
Instead, [open an issue](https://github.com/alokstates/captionshot/issues/new) that only asks for a private way to
share a security report, and the maintainer will arrange one.

This is a volunteer project, so there is no guaranteed response time.

## Checking your download

The install commands check each download against the release's `SHA256SUMS.txt` before installing it. The app is
not code-signed. Only install it using the commands in the README or from this repo's
[Releases page](https://github.com/alokstates/captionshot/releases).
